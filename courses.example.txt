# 课表模板。复制一份改名 courses.txt，改成你自己的课，然后执行：
#   npm run cli -- course import courses.txt
#
# 格式：名称 | 开课时间 | 截止时间 | 开课提前分钟 | 截止提前分钟
# 后三列都可省略，省略时按「没有截止」「提前 30 分钟」「提前 120 分钟」处理。
# 以 # 开头的行会被忽略，可以随便加注释。
# 时间写法：每周三 08:00 / 周三 08:00 / 11月5日 14:30 / 2026-11-05 08:00
# 一定要写具体钟点，只写日期会按 00:00 处理。
